1. Infrastruktur dan Deployment

VPS Production Setup

  • Deploy ulang ke VPS (76.13.17.91) menggunakan Docker Compose dengan bind mount permanen di /opt/andaralab-data
  • Data tidak pernah hilang saat rebuild container — semua JSON tersimpan di host, bukan di image
  • Nginx sebagai reverse proxy: port 80 ke frontend, /api/ di-proxy ke backend port 8080
  • Fix critical bug: nginx proxy_pass strip prefix /api/ sehingga backend return 404 — diperbaiki ke proxy_pass http://backend:8080/api/
  • Fix port conflict: PM2 (process manager) di VPS auto-restart node process dan rebut port 3001, menyebabkan Docker networking error. Diselesaikan dengan kill PM2 + reset iptables + restart Docker daemon
  • Backup otomatis harian via cron ke /opt/andaralab-backups/ dengan retensi 14 hari

Restore 106 Datasets

4. Backend API

Endpoint Baru: Lambda / Cloudflare Logs

  • GET /api/lambda/logs — return status koneksi + log entries terbaru
  • POST /api/lambda/ingest — Cloudflare Worker push logs ke backend (dilindungi X-Log-Secret)
  • DELETE /api/lambda/logs — clear log buffer
  • In-memory buffer max 500 entries, FIFO
  • Jika CF_ACCOUNT_ID + CF_API_TOKEN di-set, otomatis fetch dari Cloudflare API

5. Integrasi AWS MCP (awslabs/mcp)

Apa itu AWS MCP

  • MCP = Model Context Protocol — protokol open source dari Anthropic
  • awslabs/mcp = kumpulan MCP server resmi AWS Labs (open source)
  • Menghubungkan AI assistant dengan layanan AWS secara real-time
  • Tersedia 40+ server: CloudWatch, Lambda, DynamoDB, S3, IAM, Bedrock, dll

Server yang Relevan untuk AndaraLab

MCP Server Fungsi Relevansi
cloudwatch-mcp-server Query metrics, alarms, logs Monitor Lambda/Worker logs di admin panel
lambda-tool-mcp-server Execute Lambda functions sebagai AI tools Trigger function dari admin, akses private resources
aws-documentation-mcp-server Akses dokumentasi AWS terbaru Developer reference saat coding
iam-mcp-server Manage user, role, policy Security management infrastruktur
core-mcp-server Starting point semua interaksi AWS Koordinasi antar MCP server

Arsitektur Log Pipeline

  • Opsi A (Pull): Admin panel fetch GET /api/lambda/logs → backend call Cloudflare API → return logs
  • Opsi B (Push): Cloudflare Worker POST ke /api/lambda/ingest → buffer di backend → admin baca real-time
  • Auto-refresh 10 detik, atau push langsung dari Worker untuk zero latency
